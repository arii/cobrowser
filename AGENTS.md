# AGENTS.md
## Commands
- `pnpm dev` - start the project
- `pnpm test` - run the full test suite
- `pnpm lint` - run the lint task
- `pnpm format` - run the format task
## Code Map
- `packages/` - packages
- `services/` - application source
## Conventions
- Use `export` and `import` for TypeScript modules and `import` and `from` for Python modules.
- Name Python test files `test_*.py`.
